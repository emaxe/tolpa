# ЧЕК-ЛИСТ ГОТОВНОСТИ К РЕЛИЗУ (RELEASE CHECKLIST)

- [x] **Кроссбраузерная совместимость**:
  - Chrome / Chromium (WebGL 2.0 / WebGL 1.0)
  - Safari / WebKit (iOS & macOS, Touch Events & Web Audio unlock)
  - Firefox
  - Edge
- [x] **Управление**:
  - Сенсорное: drag / swipe / touch
  - Клавиатура: A/D, стрелки, Пробел (Адреналин), 1-4 (Формации)
  - Мышь: зажатие ЛКМ и перетаскивание
- [x] **Процедурные ассеты**:
  - 100% процедурные 3D модели Three.js (легионеры, 5 боссов, пилы, топоры, лазеры, ворота, финишная стена)
  - 100% процедурные Canvas 2D текстуры ворот
  - 100% процедурный синтез Web Audio API (звуки, музыкальные темы биомов, битвы с боссами)
  - 0 внешних файлов шрифтов/звуков/текстур
- [x] **Сюжет и локализация**:
  - Пролог, предупреждения перед боссами, финал
  - Полная поддержка RU и EN с переключением без перезагрузки
- [x] **Базовые и расширенные механики**:
  - Бег толпы до 400 юнитов
  - 4 формации (Клин, Шеренга, Фаланга, Стрела)
  - 3 спец-класса (Танк, Ниндзя, Маг)
  - Все типы ворот (+, ×, −, ÷, условные, мистические, адреналин)
  - Динамические события (засады, караваны, ЭМИ)
  - Финальная стена с множителями очков до x10.0 и сундук с конфетти
- [x] **Контент и прогрессия**:
  - 50 уровней кампании
  - 5 уникальных боссов
  - Бесконечный режим (Endless)
  - 7 веток прокачки в магазине
  - 10 достижений
- [x] **Производительность**:
  - 60 FPS на десктопе, стабильный фреймрейт на мобильных
  - < 50 draw calls за счёт InstancedMesh
  - Zero-GC в цикле `requestAnimationFrame`
  - Настройки качества графики (High / Med / Low)
- [x] **Сборка и деплой**:
  - `npm run build` успешно генерирует статический бандл в `dist/`
  - Готово к публикации на GitHub Pages, Vercel, Netlify
