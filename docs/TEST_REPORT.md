## 2. Категории тестов

1. **Математика и механика ворот**:
   - Сложение (+), умножение (×), вычитание (−), деление (÷).
   - Условные ворота (`IF mobs >= N ? ×3 : −10`): ветка PASS и ветка FAIL.
   - Спец-классы (обращение негативных ворот Хроно-Магами).

2. **Экономика и формулы**:
   - Масштабирование множителя дохода (+15% за уровень).
   - Экспоненциальный рост стоимости улучшений.
   - Стартовые легионеры от прокачки.

3. **Система сохранений**:
   - Сериализация и Base64 roundtrip экспорт/импорт.
   - Восстановление и отклонение повреждённых данных.
   - In-memory хранилище при отсутствии `window.localStorage`.

4. **Smoke-тесты генератора уровней (50 уровней + 5 боссов)**:
   - Длина трассы в диапазоне [100..500].
   - Строгая монотонность координат ворот по оси Z.
   - Корректность расположения препятствий в пределах ширины трассы.
   - Наличие и корректность параметров 5 боссов (HP > 0, атаки).

5. **Object Pool & Память**:
   - Корректный сброс состояния без аллокаций в рантайме.

6. **Формации и геометрия**:
   - Проверка расчета смещений для всех 4 формаций (Клин, Шеренга, Фаланга, Стрела).
