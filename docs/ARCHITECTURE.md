# АРХИТЕКТУРА ПРОЕКТА (ARCHITECTURE)

## 1. Архитектурные принципы и обзор системы

Проект спроектирован по модульной, слабосвязанной компонентно-ориентированной архитектуре:

```
┌────────────────────────────────────────────────────────────────────────┐
│                          React UI Layer                                │
│   (MainMenu, HUD, ShopModal, SettingsModal, AchievementsModal,         │
│    GuideModal, TestModal, LevelEndModal, DialogueModal)                │
│                                                                        │
│   Подписка на состояние: StateManager (pub/sub), EventBus              │
├────────────────────────────────────────────────────────────────────────┤
│                          3D Engine & Systems                           │
│   ├── GameEngine: WebGLRenderer, rAF Loop, Follow Camera, Lighting     │
│   ├── CrowdManager: THREE.InstancedMesh (≤400 мобов), 4 формации, классы│
│   ├── GateManager: холст-текстуры, комбо-серии, условные ворота        │
│   ├── ObstacleManager: процедурные пилы, топоры, лазеры, сбор монет    │
│   ├── BossManager: 5 боссов, телеграфы атак, фазы, хитбоксы           │
│   ├── FinishLineManager: лестница множителей x1.2..x10, сундук         │

├────────────────────────────────────────────────────────────────────────┤

│   ├── SoundEngine: Процедурный Web Audio API синтезатор                │
│   └── proceduralMeshes: процедурные геометрии мобов, боссов, текстуры  │

│                          Core & Data Layer                             │
│   ├── StateManager: централизованный стейт, сейвы, экспорт/импорт Base64│
```

## 2. Ключевые архитектурные паттерны

### 2.1. Нулевые аллокации в игровом цикле (Zero-GC)
- Все математические объекты (`dummy: THREE.Object3D`, `colorDummy: THREE.Color`, матрицы трансформаций) инициализируются один раз и переиспользуются в каждом кадре.
- `THREE.InstancedMesh` для толпы (1 draw call до 400 юнитов).
- `ObjectPool<T>` для переиспользования временных объектов и событийных структур.

### 2.2. Централизованное состояние и автосохранение
- Единственный источник правды — `StateManager` (Singleton).
- Автоматическое сохранение в `localStorage` (с fallback на in-memory для тестов и SSR).
- Возможность экспорта и импорта сохранений в формате Base64 JSON.

### 2.3. Процедурная генерация ассетов (0 внешних файлов)
- Все 3D-геометрии (человекоподобные легионеры, 5 видов боссов, препятствия, сундуки) генерируются через Three.js геометрии.
- Текстуры ворот рендерятся динамически через HTML5 Canvas 2D и преобразуются в `THREE.CanvasTexture`.
- Все звуковые эффекты и фоновые музыкальные треки синтезируются в реальном времени через Web Audio API (`OscillatorNode`, `BiquadFilterNode`, `GainNode`).
