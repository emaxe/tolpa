# 🏃 ТОЛПА — Бег к свободе (Crowd Rush)

3D-runner на **TypeScript + Three.js + React + Vite**: ведите толпу через 50 уровней
и 5 боссов-стен к Светлым Вратам. Все ассеты, уровни, звук и музыка генерируются
кодом — **ни одного внешнего файла** (кроме локализационных JSON).

## Быстрый старт

```bash
npm install        # установка зависимостей
npm run dev        # dev-сервер (Vite)
npm run build      # production-сборка в dist/
npm run preview    # локальный просмотр собранного бандла
npx vitest run     # unit-тесты и smoke-тесты генератора уровней
```

Требования: Node.js ≥ 18, любой современный браузер с WebGL.

## Развёртывание на статическом хостинге

1. `npm run build` — сборка в `dist/` (один инлайн-бандл `index.html` + папка `locales/`).
2. Загрузите **всю папку `dist`** на GitHub Pages / Netlify / Vercel / любой static-хостинг.
   `locales/` обязательна — из неё загружаются строки интерфейса.
3. HTTPS обязателен (нужен WebGL и AudioContext).

Пример для Netlify: `npm run build && npx netlify deploy --prod --dir=dist`.
GitHub Pages: залейте содержимое `dist/` в ветку `gh-pages`.

## Механики (все реализованы)

- **Толпа до 200 человек**: формации (колонна/клин/ромб/квадрат), специалисты —
  скороходы ⚡, танки 🛡, магниты 🧲, клевер 🍀.
- **Ворота**: ×2, ×3, +N, −N, ÷2, «?» (50/50), ★ (специалисты), условные (зелёная арка
  — если толпа ≥ N, красная — если < N; игрок выбирает).
- **Препятствия**: барьеры, ящики, конусы, шипы, пилы (постоянные), мины, блоки.
- **Бонусы**: ускорение, щит, магнит, адреналин, +толпа, специалисты, ×2 очки.
- **Динамические события**: метеоритный дождь, шквальный ветер, монетный дождь,
  пополнение толпы, всеобщая эйфория.
- **Комбо**: за каждые ворота без потерь — множитель очков до ×4.
- **Адреналин**: шкала → активация: скорость ×1.55, неуязвимость, очки ×2.
- **Боссы**: 5 стен с уникальными атаками (шипы, ударная волна, заморозка, мины).
  Толкайте стену всей толпой!
- **Прогрессия**: 55 уровней, звёзды (по oчкам), монеты, магазин улучшений (7 веток)
  и бустов на забег (×2 монеты, ×2 очки, +20 толпы).
- **Сюжет**: вступительный диалог, вступления миров, прелюдии боссов, финал после
  последнего босса — всё на русском (и английском).

## Производительность

- **Instancing**: толпа (1 draw call), препятствия (7), ворота (6), монеты (1),
  бонусы (1), метеоры (1), частицы (1) — **~30 draw calls** всего (лимит 200).
- **LOD**: три уровня качества (auto/low/med/high): pixelRatio, тени, декор,
  спрайты-вывески, количество частиц.
- **Без аллокаций в игровом цикле**: пулы объектов (ObjectPool), переиспользуемые
  Float32Array, бакетизация коллизий по z, модульные temp-матрицы Three.js.
- Целевые показатели: **60 FPS на десктопе, 30–60 FPS на мобильных**
  (iPhone 8 / Snapdragon 730, quality=low/auto).

## Сохранения

- `localStorage` (ключ `crowd-rush-save-v3`), версионирование + миграции.
- Автосохранение после: прохождения уровня, покупок, изменения настроек, выбора бустов.
- Сброс прогресса — в настройках.

## Тесты

`npx vitest run` — 4 файла:
- `gates.test.ts` — логика ворот (все формулы, условные арки, лимиты);
- `economy.test.ts` — цены улучшений, модификаторы, звёзды, награды;
- `saves.test.ts` — roundtrip, миграции, повреждённые данные, GameStore;
- `levels.test.ts` — smoke-тесты генератора: 55 уровней валидны, детерминированы.

Подробности: [docs/TEST_REPORT.md](docs/TEST_REPORT.md).

## Структура проекта

```
src/
  game/
    core/        EventEmitter, ObjectPool, Rng, GameState, SaveManager, Economy
    localization/LocalizationManager + public/locales/*.json
    audio/       AudioEngine (процедурный WebAudio)
    world/       LevelGenerator (55 уровней), Gates (чистая логика)
    engine/      ThreeRenderer (instancing, LOD, частицы, текстуры)
    systems/     GameEngine (системы: толпа, ворота, коллизии, комбо, боссы)
  ui/            HUD, оверлеи, экраны меню/магазина/настроек/диалогов
public/locales/  ru.json, en.json
docs/            ARCHITECTURE.md, BALANCE.md, TEST_REPORT.md, RELEASE_CHECKLIST.md
```

Полное описание архитектуры: [docs/ARCHITECTURE.md](docs/ARCHITECTURE.md).
Гайд по балансу: [docs/BALANCE.md](docs/BALANCE.md).
Чек-лист готовности к релизу: [docs/RELEASE_CHECKLIST.md](docs/RELEASE_CHECKLIST.md).

## Доступность и безопасность

- Контрастные цвета, крупные цели касания (≥44px), `aria`-метки, focus-обводки.
- Полная навигация в меню с клавиатуры; `prefers-reduced-motion` поддерживается.
- Ноль внешних зависимостей вне разрешённых (three, vite, vitest, react).
- Никаких сетевых запросов, кроме собственных `locales/*.json`.
