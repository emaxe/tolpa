# Чек-лист готовности к релизу

## Критерии приёмки (из ТЗ)

- [x] Игра запускается в последних Chrome, Firefox, Safari, Edge без ошибок
  (WebGL1/2, AudioContext, localStorage — всё стандартное; проверено сборкой
  и ручными прогонами).
- [x] Адаптивное управление: клавиатура/мышь (десктоп) + сенсор/свайпы (мобильные).
- [x] Все визуальные и аудио ассеты сгенерированы процедурно (canvas-текстуры,

- [x] Сюжетная линия: начало (диалог «Вожак»), развитие (вступления миров,
  прелюдии боссов), концовка (после босса №5) — на русском и английском.
- [x] Меню настроек: язык, качество, звук, музыка, вибрация, тряска камеры,
  FPS-счётчик, сброс прогресса — всё сохраняется (автосохранение).
- [x] Базовые механики: бег толпы, влево/вправо, препятствия, бонусы, ворота,
  финальное толкание стены (5 боссов).
- [x] Дополнительные механики: формации (клин/ромб/квадрат), адреналин,
  специализированные мобы (4 типа), условные ворота (2 арки), динамические
  события (5 видов), комбо (множитель ×4).
- [x] 50 уровней + 5 боссов, прогрессия (звёзды, разблокировки), магазин,
  бусты на забег, улучшения (7 веток).
- [x] Финальный механизм начисления очков: скорость × комбо × адреналин × бусты
  + ворота + монеты + толкание стены → звёзды и монеты (покрыт тестами).
- [x] Без критических ошибок/фризов/утечек: пулы, dispose, авто-пауза при

- [x] Производительность: instancing (~30 draw calls), LOD, лимит 200 мобов.
- [x] Код чистый, типизированный (strict), модульный, документированный.

## Риски и известные ограничения

- Процедурный музыкальный луп прост (бас+арпеджио) — при желании расширяется
  в `AudioEngine.startMusic()` без внешних файлов.
- Портретная/альбомная ориентация: игра рассчитана на обе, камера адаптивна.
- Очень старые GPU без WebGL2: Three.js автоматически работает на WebGL1.
