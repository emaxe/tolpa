# CROWD EVOLUTION 3D: Cyber Legion (Кибер Легион 3D)

Полноценная браузерная 3D игра в жанре Tactical Crowd Runner / Crowd Evolution, разработанная на TypeScript, Three.js, React и Tailwind CSS с процедурной генерацией 100% ассетов (3D моделей, текстур, звуков и музыки).

---

## 1. АРХИТЕКТУРА ПРОЕКТА (ARCHITECTURE)

Проект построен по модульной, слабосвязанной компонентной архитектуре:

1. **Рендеринг и 3D-движок (`src/engine/GameEngine.ts`)**:
   - WebGLRenderer с ACES Filmic тонемаппингом, динамическими мягкими тенями PCFSoftShadowMap и адаптивным LOD.
   - 5 тематических биомов: Неоновый Мегаполис, Магматическая Цитадель, Кристальные Недра, Квантовая Пустота, Апекс-Ядро Селестии.
2. **Высокопроизводительная толпа (`src/engine/CrowdManager.ts`)**:
   - Использование `THREE.InstancedMesh` для отрисовки до 400+ юнитов с минимальным числом draw calls (< 50).
   - Нулевые аллокации памяти в цикле `requestAnimationFrame` (0-GC) благодаря переиспользованию математических объектов (`dummy.matrix`, `colorDummy`).
   - 4 тактические формации: **Клин** (-40% урона от ловушек), **Шеренга** (максимальный охват ворот), **Фаланга** (таран препятствий), **Стрела** (+15% к скорости).
   - Специализированные классы: **Джаггернаут (Танк)** с 3 HP брони, **Кибер-Ниндзя** с 50% шансом уклонения и x2 сбором монет, **Хроно-Маг** с обращением негативных ворот в бонусы.
3. **Процедурный аудио-синтезатор Web Audio API (`src/audio/SoundEngine.ts`)**:
   - 0 внешних аудиофайлов.
   - Синтез шагов, звона ворот, сбора монет, активации адреналина, рева боссов, ударов молотов, победных фанфар.
   - Динамические фоновые треки (Кик, Басс-синтез, Арпеджиаторы) для каждого биома и битв с боссами.
4. **Квантовые Ворота & Препятствия (`src/engine/GateManager.ts`, `src/engine/ObstacleManager.ts`)**:
   - Процедурные HTML5 Canvas текстуры с динамическим разрешением.
   - Математические операции: сложение, умножение, вычитание, деление, условные ворота (`IF mobs > N ? ×3 : −10`), таинственные коробки `?` и бустеры ярости.
   - Вращающиеся пилы, маятниковые топоры, шипованные прессы, лазерные решётки.
5. **Боссы и Финальная Стена (`src/engine/BossManager.ts`, `src/engine/FinishLineManager.ts`)**:
   - 5 уникальных боссов: Меха-Голем Протокол-X (ур. 10), Магма-Колосс Игнис (ур. 20), Кристальный Змей (ур. 30), Титан-Аннигилятор (ур. 40), Апекс-Оверлорд Малакор (ур. 50).
   - Красные круги телеграфа атак, удары по земле, лазерные лучи.
   - Финальная лестница умножения очков (от x1.2 до x10.0) и разрушение королевского сундука.
6. **Централизованный стейт & Сохранения (`src/core/StateManager.ts`)**:
   - Сохранение в `localStorage`, экспорт/импорт в base64, автосохранение прогресса, звезд, монет, кристаллов, скинов и достижений.
7. **Локализация (`src/core/Localization.ts`)**:
   - Полная русская и английская локализация интерфейса, сюжета, описания улучшений и подсказок с переключением на лету.
8. **Автоматизированное тестирование (`src/testing/testSuites.ts`)**:
   - Встроенный тест-раннер с проверкой математики ворот, формул экономики, сериализации и смоук-тестами всех 50 уровней.

## 2. ГАЙД ПО БАЛАНСУ И ЭКОНОМИКЕ (BALANCE GUIDE)

| Параметр | Начальное значение | Формула прокачки / Эффект |
|---|---|---|
| Начальный отряд | 1 легионер | `1 + Level` (до 11 бойцов на старте) |
| Экономика (Монеты) | 100% | `+15%` за каждый уровень прокачки |
| Длительность Адреналина | 5.0 секунд | `5.0 * (1 + Level * 0.15)` |
| Шанс призыва Танка | 0% | `+8%` за уровень (до 40% шанса) |
| Шанс призыва Ниндзя | 0% | `+8%` за уровень (до 40% шанса) |
| Шанс призыва Мага | 0% | `+8%` за уровень (до 40% шанса) |
| Кибер-Щит | 0% | Снижение урона от препятствий на `-10%` за уровень |

## 3. ИНСТРУКЦИЯ ПО ЗАПУСКУ И РАЗВЁРТЫВАНИЮ

### Локальный запуск
```bash
# Установка зависимостей
npm install

# Запуск в режиме разработки
npm run dev

# Проверка и сборка production-бандла
npm run build
```

### Развёртывание на статическом хостинге (Vercel / Netlify / GitHub Pages)
1. Выполните `npm run build`.
2. Полученная папка `dist/` содержит оптимизированный production-бандл (HTML, JS, CSS).
3. Загрузите содержимое `dist/` на любой статический хостинг (Vercel, Netlify, Cloudflare Pages, GitHub Pages).

## 4. УПРАВЛЕНИЕ В ИГРЕ

- **ПК (Клавиатура и мышь)**:
  - `A` / `D` или `Стрелки Влево / Вправо` или Зажатие ЛКМ + движение: Маневрирование легионом
  - `Пробел`: Активация Гипер-режима Адреналина (неуязвимость и x2 скорость)
  - `1`, `2`, `3`, `4`: Быстрое переключение формаций (Клин, Шеренга, Фаланга, Стрела)
- **Мобильные устройства (Сенсорный экран)**:
  - Свайпы и удержание пальца на экране для плавного подруливания
  - Кнопка «АДРЕНАЛИН» при заполнении шкалы
  - Кнопки формаций внизу экрана
