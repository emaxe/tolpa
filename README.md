# CROWD EVOLUTION 3D: Cyber Legion (Кибер Легион 3D)

Полноценная браузерная 3D игра в жанре Tactical Crowd Runner / Crowd Evolution, разработанная на TypeScript, Three.js, React, Tailwind CSS и Web Audio API с процедурной генерацией 100% ассетов (3D моделей, текстур, звуков и музыки).

---

## 1. БЫСТРЫЙ СТАРТ

```bash
# Установка зависимостей
npm install

# Запуск dev-сервера (Vite)
npm run dev

# Запуск полного набора Unit & Smoke тестов (Vitest)
npm test

# Сборка оптимизированного production-бандла
npm run build

# Предпросмотр собранного бандла
npm run preview
```

## 2. ГЕЙМПЛЕЙ И МЕХАНИКИ

- **Толпа до 400 легионеров**:
  - `THREE.InstancedMesh` для нулевых аллокаций памяти в цикле `requestAnimationFrame` (0-GC).
  - 4 тактические формации:
    - **Клин (Wedge)**: -40% урона от фронтальных ловушек;
    - **Шеренга (Wide)**: максимальный охват монет и сбора ворот;
    - **Фаланга (Circle)**: таран и разрушение препятствий силой толпы;
    - **Стрела (Arrow)**: +15% к скорости бега и пробивание узких щелей.
  - Специализированные классы бойцов:
    - **Джаггернаут (Танк)**: 3 HP брони, уничтожает разрушаемые преграды;
    - **Кибер-Ниндзя**: 50% шанс уклонения от лезвий, x2 сбор монет;
    - **Хроно-Маг**: трансмутирует отрицательные ворота в бонусы и даёт щиты.

- **Квантовые Ворота**:
  - Операции: сложение (+N), умножение (×N), вычитание (−N), деление (÷N).
  - Условные ворота (`IF mobs >= N ? ×3 : −10`).
  - Мистические ящики (`?`) с шансом на джекпот.
  - Бустеры адреналина (`⚡ БУСТ`).
  - Динамические переворачивающиеся ворота.
  - Множитель комбо за серию успешных прохождений.

- **Препятствия и ловушки**:
  - Вращающиеся циркулярные пилы, маятниковые топоры, шипованные прессы, лазерные решётки, мины.

- **Боссы и Финал**:
  - 5 уникальных боссов (уровни 10, 20, 30, 40, 50):
    - Меха-Голем Протокол-X (Неоновый Мегаполис);
    - Магма-Колосс Игнис (Магматическая Цитадель);
    - Кристальный Змей Левиафан (Кристальные Недра);
    - Титан-Аннигилятор Пустоты (Квантовая Пустота);
    - Апекс-Оверлорд Малакор (Апекс-Ядро Селестии).
  - Телеграфирование атак красными кольцами, удары по земле, лазерные лучи.
  - Финальная лестница умножения очков (от x1.2 до x10.0) и открытие Королевского Сундука.

- **Экономика и Прогрессия**:
  - 50 уровней кампании + бесконечный режим (Endless Mode).
  - 7 веток постоянных улучшений (Начальный отряд, Доход, Адреналин, Шансы призыва Танков/Ниндзя/Магов, Кибер-Щит).
  - 10 достижений с наградами в кристаллах.
  - Сюжетные диалоги на русском и английском языках.

- **Процедурный Web Audio API Синтезатор**:
  - 0 внешних файлов: процедурный синтез звуков шагов, сбора монет, активации адреналина, рева боссов, ударов, победных фанфар.
  - 5 фоновых музыкальных тем для биомов и битв с боссами.

## 3. ТЕСТИРОВАНИЕ

Все модули покрыты автоматическими тестами:

```bash
npm test
```

- Математика и логика ворот (сложение, умножение, вычитание, деление, условные ворота).
- Экономика и прокачка (формулы стоимости, модификаторы, стартовые мобы).
- Система сохранений (Base64 сериализация, импорт/экспорт, восстановление после повреждений).
- Smoke-тесты генератора уровней: 50 уровней кампании, 5 боссов, монотонность координат, границы трассы.
- Object Pool и проверка памяти (нулевые аллокации и корректный сброс состояния).
- Встроенный в UI интерактивный Test Runner (кнопка `ТЕСТЫ & АРХИТЕКТУРА` в меню).
